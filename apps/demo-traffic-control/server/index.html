    멈춤은 무엇을 멈추나요?

    새 요청만 멈춥니다. 이미 보낸 요청은 끝까지 저장을 확인합니다. 그래서 멈춰도 잃는 요청이 없습니다.

    왜 끄고 켜나요?

    평소에는 꺼 두어 DB 가 쓸데없이 커지지 않게 하고, 시연 때 켜서 이전 중에도 요청이 끊기지 않는지 보여 줍니다.

    안전장치

    DB 이전(전환)이 진행 중이면 버튼을 잠급니다. 전환 도구가 요청 흐름을 다루는 동안 사람이 끼어들지 않게 하려는 것입니다.
